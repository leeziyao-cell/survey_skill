# survey_bluewrite

## 文风目标

让首次接触本节主题的读者知道：现在要解决什么问题，为什么比较这些方法，它们的差别说明了什么，接下来还需要理解什么。讲清方法做了什么、结果怎样被使用，并让必要的机制细节和文献证据共同支撑更大的判断。

在事实与证据准确的前提下，先保证观点解释充分、例子承接自然，再压缩表达。压缩应删去重复介绍、无关细节和空泛收束，保留读者理解观点、机制和比较所需的解释；篇幅较短或段数较少本身不代表写得更好。

从初稿或已有蓝图生成、扩改文献论述正文时，本会话首次执行先读[作者认可的完整正文与三项标注](references/approved-wm-prediction-section.md)，参照其解释深度及例证连接方式。已读则复用，不要求作者先验收样段，也不重读整篇参考论文。只设计蓝图时，将下文三项标准落实为段落安排即可。

本项目中，以作者修订后的 Ch3、Ch4 中文正文作为正面写法参照，不把旧初稿的表达当成标准。可以用于其他章节和相近学术写作，但不迁移这些章节的分类、例子、技术结论或固定顺序。正文写成连贯的学术段落，蓝图说明论证安排，详略服从当前任务。

## 适用范围与协作

- 用于根据结构和文献生成或修订段落蓝图，检查正文与配图是否落实蓝图，以及正文撰写、扩改、翻译润色、代表工作、比较、挑战和图注的表达。
- 作者要蓝图时交付蓝图，要正文时写正文；同时要求先安排后写作时，先说明逻辑安排再写指定范围。用户要求改文件时修改指定文件，不根据短提纲自行扩成整章。
- 用户提供初稿，或提供范围明确的写作蓝图及可用文献证据，并要求正文时，直接完成指定范围的正文。初稿用于恢复原意和发现解释缺口；蓝图用于恢复各段共同回答什么、每段新增什么及证据位置。将蓝图中的比较依据和理解难点展开成解释，不逐条改写成论文介绍，也不把重新交蓝图或继续磨样段作为默认前置步骤。
- 本 skill 组织节内问题、段落比较和论证顺序，并检查正文是否落实。需要新增或改变章级组织、主分类轴或章节边界时，使用同目录的 [design-survey-chapter](../design-survey-chapter/SKILL.md)；普通段落安排或措辞调整不触发结构重设计。
- 按用户已授权的范围工作。润色不改变原有证据强度、实验条件、taxonomy 或主要结论；发现实质逻辑缺口时简短指出，不用顺畅措辞掩盖问题。

## 根据结构和文献生成蓝图

作者给出章节结构和文献包，即可直接规划段落，不以已有蓝图为前提。文献包可以是索引、已有核查、原文及定位；从这些材料和当前会话恢复目标，不额外要求整篇正文、固定表格或一轮新审计。

蓝图与正文采用下文同一套论证标准。先形成有证据的比较和认识，再安排自然段；作者给定篇幅或约三段等要求时，在该范围内取舍例证，不把某次段数变成通用模板。

交付覆盖指定范围的一份蓝图：说明各节核心问题与整体推进；逐段讲清读者应获得什么认识、这一认识需要怎样解释、哪些文献在何处支持或限定它，以及为什么接下一段。仅写讨论主题、比较对象和论文分配，还不足以指导正文展开。定义段、导入段和流程说明段按其实际用途说明要讲清什么，不强求独立结论。信息可以合写，不必固定拆成栏目。附决定性原文位置、核查状态和证据缺口，具体按[蓝图的证据使用](references/blueprint-evidence.md)处理。

蓝图不自动授权写整章、改目录或扩大文献范围。证据与给定结构冲突时，指出具体影响并完成其余有支撑的安排；蓝图转为正文时继续检查论证，不机械展开提纲或堆入全部细节。

## 推敲深度与正文表达

无论推理强度是高、极高或其他设置，都保持同一文风。更充分的推敲用于核对事实、辨别方法差异、检查因果和删减冗余。正文只呈现完成当前写作任务所需的事实、比较和判断。

不要把内部分析全部写入正文，也不要为了显得深入而增加术语、分类层级、篇幅或反复保留意见。用户没有索要分析过程时，直接交付写好的文字；修改文件后简要说明改动与关键核查。

## 先落实论证，再润色句子

围绕“研究问题 → 比较依据 → 方法证据 → 跨方法比较 → 综合认识”组织本次内容。这是从材料形成论证的过程，不是每段必须依次填满的五个栏目。分类或比较依据应由文献真实差异支持，不能预设一个漂亮结论再找论文填充。

写作前恢复以下关系，优先使用已确认的蓝图，不另建流程文件。局部任务只检查与当前文字有关的层次和相邻内容。

| 层次 | 正文需要让读者看明白什么 |
| --- | --- |
| 全文与章节、小节之间 | 本章承担哪个分析任务，各节分别补上哪一部分回答；为什么先讲 A 再讲 B，二者是并列、递进、条件补充，还是从方法转向评价。 |
| Section 内部 | 本节要回答的具体问题是什么，按什么依据展开文献，各组内容分别回答什么，最后能从比较中得到什么认识。按不同问题展开时，不强称为互斥方法类别。 |
| 段落之间 | 上一段已经说明什么，本段新增什么；它是在对比另一种办法、补充条件，还是处理尚未回答的问题。并列内容不必编成前者失败推动后者出现的故事。 |
| 段落内部 | 主题句点明本段要解释的问题或有证据的判断；必要的概念、机制和例证支撑它；比较或收束让读者知道差别及其意义。定义段、导入段或单篇机制例证按实际作用写，不强凑比较。 |

连接应体现在内容中。例如，“知道目标位置后，还不能判断机械臂沿途能否避开障碍”解释了为什么从位置进入运动条件；仅增加“进一步”“此外”没有建立这层关系。这是论述的推进，不能据此虚构方法之间的因果、历史演化或系统执行顺序。

## 写作规则

### 1. 写清主体、动作和变化

优先说明“谁遇到什么问题，谁做了什么，之后发生什么变化”。在具身决策中，需要时讲清：机器人要完成的任务、模型得到的观察、模型提供的信息，以及规划器、控制器或学习模块怎样使用这些信息。

不要把多个模块的贡献都归给一个模型。例如，VLM 找到目标位置、LLM 安排步骤、运动规划器计算轨迹，应按实际分工写。若内容属于理论或训练方法，则围绕研究对象、假设、训练信号、计算过程或结果解释，不强行插入机器人场景。

### 2. 从证据形成段落中心意思，用主题句引导阅读

推敲时，先核对文献做法、真实差别和成立条件，再形成比较与判断；成文时，可以先用已有证据支持的主题句告诉读者本段要解释什么，再展开机制和文献。不要把“证据先于判断”误写成“必须先列论文，最后才说本段主旨”。

一段围绕一个主要问题，并让读者获得明确的认识。“比较三种状态表示”只说明论述任务，还需讲清这些表示分别保留什么信息、这种差别为什么影响后续预测。中心意思可以是机制、差别、条件或证据支持的判断，不必是效果优劣或新的宏观结论；定义、导入和流程说明按实际作用组织。

选入的方法、例子和技术细节应支撑这一中心意思，或帮助读者理解后续比较。代表工作不必凑齐任务、输入、输出、优点、局限五项。论点必须由已有证据支持；证据不足时缩小判断或指出缺口，不为使观点鲜明而补造因果和普遍结论。

### 3. 解释观点、连接例子，并按需要收束

**观点后进一步解释。** 观点句提出后，用具体过程、原因或后果讲清本段具体意味着什么、为什么成立。解释应让读者理解比较为何必要，不能只是换词重述观点，也不能把逐篇列出机制当成已经完成解释。机制、实验结果或相邻文字已把道理讲清时，保留这层说明即可，不另凑解释句数。

**用连接句引入例子。** 在观点或解释之后，说明接下来的工作将回答哪个具体问题、补充哪类信息或形成什么对照，让例子接住刚讲清楚的问题。连接可以独立成句，也可以融入例子开头；只有“例如”“进一步”或论文名称，不足以建立这层联系。文献按证据需要穿插，不将这一安排固化为每个例子都要重写一遍观点和背景。

**按论述是否完成选择总分或总分总。** 解释和例子已把观点讲清时，总分结构即可结束。例子之后还能比较不同做法、说明使用条件、提出有前文依据的未解问题或形成进一步认识时，再保留段尾综合。收束应增加认识，不能重复段首和论文名单。总分与总分总按内容选择，不固定段数、例子数、句数或总结句式。

首次出现、且影响理解的概念，说明它是什么、为什么需要、怎么用，按实际需要取舍。先用一句完整的话解释，再保留必要术语。

例如，场景图可以解释为“用节点表示物体，用连线表示物体之间的关系”；状态更新可以解释为“物体被移动后，修改原来保存的位置”。不要只用另一个抽象词解释新词，也不必重复解释读者已知的基础概念。

### 4. 把比较和局限写成可理解的差别

先明确比较的是哪些对象、共同回答什么问题，以及本次依据什么差异比较。同一组比较保持依据一致；需要转向另一维度时，说明它与前一问题的关系或主次层次。不能把任务场景、反馈位置和模型结构无说明地混作同层类别。

说明方法之间究竟哪里不同，这个差别会怎样影响使用。例如，一个方法只给操作位置，另一个方法还给出运动中需要满足的条件；一个方法只看当前图像，另一个方法还参考此前执行过的步骤。

写出对应差别怎样形成有条件的取舍，而不只给各篇论文分别贴优点标签。重要的综合句应能回指前文证据，解释差异对解决问题或使用选择意味着什么，例如适合哪种需求、为什么需要某类信息、代价来自哪里。“不能直接比较／替换”只界定边界，“各有优势”“提升了性能”或重复论文名单也不能代替综合；证据足够时应提炼已有认识，确实不足时说明哪条判断尚不能形成。单篇内部对照、跨论文机制比较与不同实验设置下的结果比较应分清。

“提高鲁棒性”“具有更强泛化能力”“实现语义对齐”等表述只有在明确对象、条件或证据时才有意义。优先写明改善了什么、在哪种情况下有效。

局限应说明具体原因及其后果，如“目标位置识别错误，会使规划器朝错误位置运动”。不要给每项工作机械补上“仍有局限”或“不保证成功”。不同实验条件下的结果不能直接用来排列方法高低。

### 5. 选择文献并保留证据边界

分别检查引用是否准确、选文是否充分。前者确认论文支持相邻事实或判断，后者检查它是否适合当前问题、覆盖重要差异并提供额外证据。核实方法细节不等于已经证明本节的文献选择充分。

- 按当前论证问题重新选择主例和对照，优先利用已有文献池。不默认延续前文用过的模型或简短回指；其他独立研究更能支撑当前判断时，直接换用，也不为减少重复而换入同质或不匹配的论文。
- 复引应有明确任务，说明本次使用哪项机制、实验或发现。前文已经引用过不构成继续引用的理由；同一实验多次出现不增加独立证据。不设置固定引用数量或复引次数，也不要求每段更换论文。
- 分开判断技术路线与实验贡献。共享基座或存在技术继承，不自动构成独立技术路线；后续研究的新实验仍可能提供独立贡献，要看它实际增加了什么证据。

- 区分原论文事实、本文的组织方式和作者综合判断，不把推断写成论文已验证的结果。
- 引用紧贴它支持的事实或判断。保留必要实验条件和限定词，不为了简洁而删去影响结论的条件。
- 优先使用当前任务已有的可靠材料。普通措辞修改不重复开展文献检索；新增具体任务、实验细节或方法能力时，先核对原论文或官方资料中尚未确认的部分。
- 代表工作使用真实任务例子。若只为解释概念而构造例子，应明确是假设情形，不暗示论文做过该实验。证据不足时保留原有概述或指出待核查内容，不补写看似合理的细节。
- 能够给出位置、计划或解释，与这些输出能够改善实际任务表现，是不同的结论；按证据支持的程度书写。

### 6. 使用自然、准确的句子

一句话围绕一个主要意思；步骤或转折过多时拆开，但保留必要的因果关系。优先使用明确主语和常见动词，避免连续堆叠抽象名词。

减少没有具体解释的“赋能、协同机制、能力边界、闭环优化、多维融合、范式升级”等概括性表达。它们不是禁词；确有技术含义时说明含义，不把术语替换成含混口语。

段落之间用真实的问题递进或方法差异衔接。不要反复以“因此”“总体而言”重述前文；没有新增判断的总结句可以删除。正文不写成口号、提纲、连续问答或固定的“不是……而是……”句式。

### 7. 根据段落用途调整重点

- **二级标题导入**：每个二级标题后的第一段，用直白的话说明本节讨论什么、范围是什么，必要时说明接下来怎样展开；不引用文献，不罗列论文或模型名称。具体方法、实验结果及需要文献支持的学术判断放到后续段落中。避免空泛背景和逐项复述全部小标题。
- **代表工作**：选择能说明当前比较或判断的任务，顺着过程讲清模型提供什么、机器人随后怎样行动。保留首次阅读者理解差别所需的机制细节；输出清单、模块和实验设置即使属实，与当前比较无关时也应压缩。不连续堆放各篇论文的创新点来代替比较。
- **主要挑战**：从已有方法做到哪里，说明仍然难在哪里，再提出具体待研究的问题；需要时说明怎样评价进展。不要把风险表逐项改写一遍，也不强迫每项挑战有相同长度或结构。
- **图注**：让读者能理解任务、面板、关键符号及比较依据。偏好比较应说明“相对于什么任务更好”。按实际记录交代素材出处，并区分实验画面、本文标注和示意改绘；不能把示意标注写成模型实测输出。图注不重复整段方法介绍。

## 表达示例

下面只示范表达方式，不作为任何具体论文的事实或引用。使用具体做法前，仍须确认当前材料支持它。

| 避免空泛概括 | 改为具体解释 |
|---|---|
| 通过语义空间表征实现任务条件到动作执行的有效衔接。 | 模型指出目标位置和需要避开的区域，运动规划器据此计算机器人怎样移动。 |
| 动态环境对记忆一致性提出了更高要求。 | 物体被移动后，机器人如果继续使用旧位置，就可能找错地方。 |
| 多源反馈赋能闭环恢复机制。 | 系统结合执行记录和新的观察判断失败原因，再修改后续步骤。 |

概念与难点的表达示例：

> 此前记录的物体不再出现在当前画面中，既可能是位置发生变化，也可能只是暂时被遮挡。直接删除旧记录可能丢失仍然有效的信息，继续沿用旧记录则可能使机器人前往错误位置。因此，需要结合观察历史判断哪些记录应当保留，哪些需要修改，以及何时应重新观察。

该示例的重点是解释两种可能原因和相应后果，不是要求所有段落都以“因此，需要……”结尾。

## 最小执行与自检

1. 读取用户指定的有效材料、已有蓝图及必要的相邻文字，确定本节的问题、当前段落的作用和所需证据。只读与任务有关的部分，不默认重做整章规划。
2. 按证据组织主题、机制、比较与判断；只补查新增事实所需的材料。保留原有引用键、术语和实验条件，除非修改它们属于已授权任务。
3. 交付前按从大到小的顺序在内部检查并修正：
   - **先看 Section**：核心问题和分析任务是否明确；各下级标题和段落分别补上哪部分回答；分类或比较依据是否一致，各组证据能否支持本节综合。涉及未获授权的结构或结论变动时指出具体缺口，不用润色掩盖。
   - **再看段落关系**：仅概括各段中心意思，能否看出它们怎样共同回答小节问题；每段新增什么，顺序有什么理由。不能只换一批论文或靠连接词制造递进；定义、例证和比较应处于清楚的主次层次。
   - **再看段内论证**：从实际正文检查三项标准。观点及解释是否让首次阅读者知道本段具体意味着什么、为什么成立；方法名称出现前，或例子开头，读者是否已经知道为什么要介绍它；段尾是否增加比较、使用条件或进一步认识。发现解释不足就补写具体过程、原因或后果，发现例子突入就补上它与问题的联系，发现收束重复就删除或改写。不能仅凭有主题句、方法介绍和总结句判定通过，所有解释与综合仍须符合证据范围。
   - **最后看句子与引用**：谁做了什么、结果怎样使用是否清楚；抽象名词、长句和套话能否改为具体过程；引用是否支持相邻判断，选文是否适合当前问题并提供必要的独立证据，有无无依据的细节、因果或能力评价。
