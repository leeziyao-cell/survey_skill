# 标准样段：预测后果怎样参与动作选择与修正

作者于 2026-10-26 整体认可该样段，并于 2026-10-27 确认按后续敲定的表述更新。以下保存最终版本。修改理由依据已有批注与修订过程整理，用于解释写作组织。

## 段落位置与承接

该段位于“预测辅助的动作选择与规划”小节，承接上一段已经区分的两种做法，即生成期望未来后求动作，以及预测候选动作的后果后选择动作。这里继续回答预测后果怎样成为选择或修正动作的依据。

## 作者认可的正文

```latex
要把候选后果用于动作选择，还需要判断这些后果是否符合任务要求。预测结果可以先经过任务评价，再用于选择或优化动作，也可以直接以未来特征参与策略修正。按任务评价筛选候选时，SafeDreamer~\cite{safedreamer2024} 的在线规划变体用 WM 预测候选动作序列的未来隐状态、奖励与安全成本，在任务收益与约束要求之间权衡。DreamNav~\cite{dreamnav2025} 则在机器人导航中，用 WM 根据候选路线生成第一视角未来视频，将视频概括成文字描述，再由导航决策模型比较路线与当前指令子任务的符合程度并选路。任务评价还可以用于继续调整动作。GPC~\cite{gpc2025} 用 WM 预测多组候选动作的后果，按预测奖励选出动作序列，也可以从已有动作出发，通过 WM 的梯度优化动作以提高预测奖励。直接利用未来状态时，LaDi-WM~\cite{ladiwm2025} 根据初步动作预测未来特征，再将特征送回策略生成修正后的动作序列。IRASim~\cite{zhu2024irasim} 的物体推动仿真显示，未用策略执行轨迹补充 WM 训练时，规划器用预测后果比较更多候选动作，执行后物体与目标形状的平均重合程度反而下降。任务评价可以引导动作选择与优化，未来特征可以直接改变策略输出，而扩大搜索的收益仍需结合具体执行结果判断。
```

## 修改理由

- **段首先接住已经建立的问题。** “候选后果用于动作选择”接住上一段的候选比较，再以“是否符合任务要求”引出评价，不突然换题。
- **总句交代后文的两种用法。** 任务评价用于动作选择或优化，未来特征直接参与策略修正。这些用法可以结合，不作为互斥的模型分类。
- **例子按分论点组织。** SafeDreamer 和 DreamNav 并行说明任务评价怎样进入候选筛选。GPC 接着说明评价还可以用于继续优化动作。LaDi-WM 说明未来特征直接返回策略的做法，与经过任务评价的做法形成比较。这里的承接是论证关系，不是论文之间的历史影响或共同系统中的模块调用。
- **模型作用落实到具体过程。** 每项工作说明 WM 输出什么、输出由谁使用、怎样影响动作。文献名紧跟引用，每篇文献集中解释一次，不靠“前者／后者”回指或重复分述维持比较。
- **例子按完整意思压缩。** LaDi-WM 用一句说明未来特征如何返回策略并修正动作，直接写作用。IRASim 用一句连接训练条件、候选比较和执行结果。省去“不用评分”的额外否定说明和“执行是否改善仍需检验”的泛泛过渡。
- **反例承担明确的证据作用。** IRASim 用于说明扩大候选搜索未必改善执行，保留必要的训练条件、仿真场景和结果方向。这里的论点不依赖差异幅度，因此不列候选数量和 IoU 的具体数值，也不把退步单独归因于预测器或评价器。
- **段尾回收本段已经展开的内容。** 汇总任务评价与未来特征对动作计算的不同作用，并用执行结果限定搜索收益，不临时引入新的比较维度或挑战。
